# AGB Finance - Ипотечен Кредит

A modern React application for AGB Finance mortgage loan services, built with React, CSS Modules, and SASS.

## Features

- **Responsive Design**: Mobile-first approach with modern UI/UX
- **Contact Form**: Complete mortgage loan application form
- **Branch Information**: Contact details for Sofia and Sunny Beach branches
- **Modern Styling**: CSS Modules with SASS for maintainable styles
- **Accessibility**: WCAG compliant with proper focus management
- **Performance**: Optimized for fast loading and smooth interactions

## Technologies Used

- **React 18**: Modern React with hooks
- **CSS Modules**: Scoped styling for components
- **SASS**: Advanced CSS preprocessing
- **Responsive Design**: Mobile-first approach
- **Modern JavaScript**: ES6+ features

## Getting Started

### Prerequisites

- Node.js (version 14 or higher)
- npm or yarn

### Installation

1. Clone the repository:
```bash
git clone <repository-url>
cd agb-finance
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm start
```

4. Open [http://localhost:3000](http://localhost:3000) to view it in the browser.

### Available Scripts

- `npm start` - Runs the app in development mode
- `npm build` - Builds the app for production
- `npm test` - Launches the test runner
- `npm eject` - Ejects from Create React App (one-way operation)
